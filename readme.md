# SkyTrip 网页演示

双击打开 [SkyTrip_Preview.html](SkyTrip_Preview.html)。可将该 HTML 文件单独发给组员，对方下载后可离线打开。页面中的操作保存在当前标签页的内存，刷新会恢复统一样本。此版本的运行方式为浏览器模拟。

## 演示顺序

1. 首页保留默认的 Hong Kong → Shanghai 和 2026-11-23，可见三班直飞，覆盖 SHA 和 PVG。
2. 打开 ST101，选择 Alice Chen，创建新行程。输入两名乘客，切换舱位查看经济舱报价 1,044.00 元与商务舱报价 2,320.00 元，再切回经济舱并创建预订。
3. 在行程详情选择模拟支付失败，然后点击重新预订。旧记录保留为 FAILED，新记录为 PENDING。对新订单模拟支付成功，再查看 CONFIRMED 和支付记录。
4. 进入 Reviews，将演示时间切到 11 月 25 日，提交 ST101 的评论。该班次随后从可评论列表消失。

新预订采用已确认的演示报价规则：经济舱基础价优惠 10%，商务舱为基础价两倍且包含贵宾室。既有订单保留原快照及权益。

已使用 Edge 验证从本地文件进入的交互流程、两种舱位报价、失败重试、成功支付、抵达后评论、统计、手机宽度及刷新重置。此次验证记录的是网页模拟行为。课程报告里的十一表建库、正式 SELECT 和执行结果沿用对应的数据库材料。
